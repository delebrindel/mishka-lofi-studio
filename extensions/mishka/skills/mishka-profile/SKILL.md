---
name: mishka-profile
description: Select or show the musical profile for new Mishka briefs.
disable-model-invocation: true
---

Pass `mishka`, `mishka+voice`, `rock`, or `rock+voice` to select a profile for this Pi session. With no argument, show the active profile.

This skill requires the Mishka Pi extension. If Pi shows these instructions instead of running the action, load the extension before retrying.
